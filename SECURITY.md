# Security Policy

## Pelaporan kerentanan

Untuk celah keamanan pada aplikasi ini, gunakan fitur **Report a vulnerability** pada tab **Security** repository GitHub jika pemilik repository telah mengaktifkan *private vulnerability reporting*. Sertakan langkah reproduksi dan dampaknya. Jangan membagikan kata sandi, token, atau detail eksploitasi lewat issue publik.

Jika fitur pelaporan privat belum tersedia, hubungi pemilik repository melalui kanal privat yang mereka cantumkan di profil GitHub. Pemilik repository sebaiknya mengaktifkan *private vulnerability reporting* setelah mengunggah proyek.

Untuk celah pada framework Laravel sendiri, ikuti [petunjuk keamanan resmi Laravel](https://laravel.com/docs/security#reporting-security-vulnerabilities).

Sebelum digunakan secara publik, jalankan aplikasi melalui HTTPS, gunakan layanan email yang berfungsi, lindungi konfigurasi `.env`, dan terapkan pembaruan keamanan Laravel secara rutin.
